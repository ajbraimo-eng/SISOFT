# Ícones — Glass Dock

Para aproximar o mockup (pastas coloridas + ícones flat):

## Pastas Quick Access

Substitua ícones das pastas do utilizador:

1. Clique direito na pasta → **Propriedades** → **Personalizar** → **Alterar ícone**
2. Use um pack `.ico` colorido (Desktop verde, Documents amarelo, Downloads azul, etc.)

## Packs sugeridos

- Windows 11 Fluent Colorful
- Haiku Folder Icons
- Papirus (adaptado) / Colorful Folders

## Tema de ícones do sistema

Ferramentas: **IconPackager**, **CustomizerGod** (avançado), ou **Rectify11**.

Evite misturar packs demasiado “skeuomorphic”; o mockup usa formas simples e cores sólidas saturadas.
