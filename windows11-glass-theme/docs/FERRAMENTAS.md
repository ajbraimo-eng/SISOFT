# Ferramentas recomendadas — Glass Dock

## Obrigatórias para o look do mockup

| Ferramenta | Função | Link |
|---|---|---|
| RoundedTB | Taskbar em pill / dock flutuante | https://github.com/torchgm/RoundedTB/releases |
| TranslucentTB | Transparência da taskbar | https://github.com/TranslucentTB/TranslucentTB/releases |
| MicaForEveryone | Acrylic/Mica nas janelas (Explorer) | https://github.com/MicaForEveryone/MicaForEveryone/releases |
| Rainmeter | Barra de pesquisa flutuante | https://www.rainmeter.net/ |

## Opcionais (mais próximo do mockup)

| Ferramenta | Função | Link |

| StartAllBack / Start11 | Start menu custom (pago) | — |
| ExplorerBlurMica | Blur alternativo no Explorer | https://github.com/Maplespe/ExplorerBlurMica |

## Ícones coloridos (estilo mockup)

- Fluent Icons / Windows 11 Icon Pack
- Colorful Folder Icon Pack (pastas Desktop, Documents, etc.)
- Seagull Icons / Fluent Colorful

Aplicar com **IconPackager** (pago) ou substituindo ícones de pastas (Propriedades → Personalizar).

## Mods Windhawk úteis

1. **Windows 11 Taskbar Styler** — estilo dock
2. **ExplorerFrame** / mods de navegação — cantos e chrome
3. **Taskbar height and icon size** — ícones do dock mais compactos

## Ordem sugerida de instalação

1. Ponto de restauro do sistema
2. Aplicar `scripts/Apply-GlassDock.ps1`
3. TranslucentTB
4. RoundedTB (Dynamic Mode)
5. MicaForEveryone
6. Rainmeter → GlassDockSearch
7. Pack de ícones
